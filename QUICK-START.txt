🛠️ TROUBLESHOOTING
─────────────────────────────────────────────────────────────

Dashboard won't load?
  cmd> cd dashboard\web
  cmd> npm run dev

Database not running?
  cmd> docker-compose up -d postgres

Port 3000 in use?
  cmd> netstat -ano | findstr :3000
  cmd> taskkill /PID <PID> /F
